# Evaluation

## Primary Metric

**Correct Verdict Rate (CVR)** — fraction of cases where overall verdict (PASS / FAIL / INSUFFICIENT_EVIDENCE) matches programmatic ground truth.

## Secondary Metrics

- Per-metric status accuracy
- False PASS count (predicted PASS when gold ≠ PASS)
- Unsupported claims (PASS/FAIL without evidence_id)

## Running Evaluation

```bash
./scripts/run_evaluation.sh
```

Outputs:
- `results/eval_report.md`
- `results/eval_report.json`
